CLONE

AI-Assisted IntelliJ Plugin for Clone Refactoring

CLONE helps Java developers detect duplicated code introduced through copy-and-paste, review an Extract Method refactoring, check the validation evidence behind it, and apply the change only when they are confident it is correct.

Watch the demo Research Paper View on GitHub

About CLONE

CLONE is an AI-assisted IntelliJ plugin feature that helps Java developers detect duplicated code introduced through copy-and-paste and review Extract Method refactoring suggestions before applying them. It extends the AntiCopyPaster workflow by adding a clearer review process where the developer can inspect the detected clone, see where it appears, compare the proposed code change, and decide whether the suggestion should be applied. Instead of showing only a generated refactoring result, CLONE presents the clone type, affected locations, selected code ranges, proposed helper method, diff preview, and validation status in one review workflow.

The goal of CLONE is to make duplicate-code refactoring more understandable, transparent, and developer-controlled. The interface supports multiple clone occurrences, allowing users to include, exclude, or inspect individual duplicates before continuing. It also provides validation evidence such as clone detection, refactoring generation, usefulness checking, compilation results, and test or behavior-preservation checks. These signals do not guarantee correctness, but they help developers assess whether a suggestion is ready to apply while still keeping the final decision in their hands.

User Testing

The team prepared a standardized instruction sheet and Microsoft Form for people testing the CLONE plugin. Eight participants used a small duplicated Java code example and submitted feedback about the redesigned interface. Five rated the overall experience as good and three rated it as neutral, with no negative ratings. The Diff Preview was selected most often as the interface's most useful feature.
