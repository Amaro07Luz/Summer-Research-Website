CLONE

AI-Assisted IntelliJ Plugin for Clone Refactoring

CLONE helps Java developers detect duplicated code introduced through copy-and-paste, review an Extract Method refactoring, check the validation evidence behind it, and apply the change only when they are confident it is correct.

Watch the demo Read the final report View on GitHub

About CLONE

Duplicated Java code often appears when a developer copies and pastes existing logic instead of extracting it into a shared method. Once duplication exists, every future change to that logic has to be repeated in each copy, which makes the codebase harder to maintain and easier to get wrong. CLONE detects duplication at the moment it is introduced and proposes an Extract Method refactoring to remove it, showing the developer what was found, what will change, and the evidence behind the suggestion before anything is applied.

User Testing

The team prepared a standardized instruction sheet and a Google Form for people testing the CLONE plugin. Testers use a small duplicated Java code example, since the plugin relies on API tokens during detection, refactoring, validation, and testing. Each team member is finding two to three users to test the plugin and submit feedback, which will be summarized into graphs for the final report.
